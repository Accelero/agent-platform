Release 0.4.1 removed unused image-build SSH host keys and an inherited
snakeoil TLS private key. Runtime host keys are generated at startup. Release
and cache builds use finite, reviewed inputs from `release-policy.json` and
`agent_platform/privacy.py`; private configuration, prompts and credentials enter
only through mounted runtime inputs. The tools image copies its cleaned
filesystem into a scratch stage to exclude inherited key layers.

Local qualification used disposable containers. Live rollout, application login
and task execution remained separate deployment checks. Detailed historical
validation evidence remains in Git history.

## Retired images

After the replacement passed qualification, the affected agent-runtime 0.2.0,
0.3.0 and 0.4.0 versions and tools 0.4.0 were removed, including their platform
and provenance manifests: 12 GHCR version records in total. Both package identities,
0.4.1 manifests and their `latest` tags were verified intact. Historical Git tags
and release/chart records remain as provenance; their retired image dependencies
make older releases unavailable for deployment.
