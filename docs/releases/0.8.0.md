# Agent platform 0.8.0

Published on 2026-11-12 from `053d0c27dc11361f6e9faeb8337ed1ba082f7449`.
The [release workflow](https://github.com/Accelero/agent-platform/actions/runs/43319069755)
passed its full hosted suite: 1448 tests passed and one optional test skipped.
The [GitHub Release](https://github.com/Accelero/agent-platform/releases/tag/v0.8.0)
contains the same chart package as GHCR.

The chart and tools image now provide application recovery API 1. The platform
owns dataset/Secret inventories, consistent capture, full-payload validation,
transactional database restore and dispatch fencing. Consumers retain storage,
credentials, S3/restic transport, encryption, scheduling and teardown ordering.
See [the recovery interface](../recovery.md) for configuration and operations.

Schema 3 records the source logical inventory and its digest. The reader also
supports legacy schemas 1/2 and existing completion pointers/journals. Keep the
last compatible recovery point because pre-API consumers reject schema 3.
Hindsight is outside this singleton inventory and must remain disabled when
using this recovery contract.

Failed final checkpoints can withdraw deletion proof after their normal budget
expires, within a fixed part of the Job's cleanup reserve. Failed withdrawal
keeps writers stopped. Consumer updates must verify the archive with candidate
tools and run `invalidate-cutoff` before Helm can restart writers. The operation
holds the shared lease and changes neither the claim fence nor replicas.
`verify-final` records deletion intent, blocking subsequent administrator work
and bootstrap. Abandoned teardown requires the manual inspection and recovery
procedure in the recovery guide; no operation automatically removes the marker.

Local checks include the recovery/chart/bootstrap suite, both repositories'
golden inventory digest tests, the candidate tools image, encrypted MinIO
readback and transactional PostgreSQL recovery. Live deployment, Helm timing,
planned down/up and lost-VM recovery remain separate qualification steps.
